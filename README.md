# Game Project

目标：复原经典单机游戏的原型合集（HTML5 Canvas），先做“多游戏选择菜单 + 2~3 个原型”。

## 当前包含
- 蘑菇冒险（横版跑跳采蘑菇）
- 魂斗罗·迷你版（横版射击）
- 打砖块（反弹球）

## 本地运行
在项目根目录执行：

```bash
python3 -m http.server 5173
```

然后在浏览器打开：

```
http://localhost:5173
```

## 操作说明
- 蘑菇冒险：方向键移动/跳跃，Z 加速，X 攻击，R 重开，P 暂停
- 魂斗罗·迷你版：方向键移动，Z 射击，X 跳跃，R 重开，P 暂停
- 打砖块：方向键移动挡板，R 重开，P 暂停

## 新增优化
- 关卡选择（1-3）与通关记录保存
- 设置面板：音量与像素风渲染开关
- 关卡结算：下一关 / 重试 / 退出
- 像素素材升级：多帧小动画
